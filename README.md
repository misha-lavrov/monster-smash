# ⚔️ Побий монстра! — міні-гра для майстер-класу ОІПЗ

Невелика гра, у якій **браузер** — це «обличчя», а **Java-сервер** — «мозок».
Змінюєш правила гри в одному файлі → перезапускаєш → бачиш результат.

Потрібно: **JDK 17+** (найпростіше — портативний JDK у папці `jdk\`). Інтернет не потрібен.
Репозиторій: <https://github.com/misha-lavrov/monster-smash>

## Запуск

| Спосіб | Як |
|---|---|
| **IntelliJ IDEA** | File → Open → папка `monster-smash` → зелений **▶** біля `main` у `src/Main.java` (або конфігурація «Запустити гру») |
| **Двічі клікнути `start.bat`** | збирає й запускає гру, а Chrome відкриває сам — **лише якщо сторінки гри ще немає** |
| Вручну | `javac -encoding UTF-8 -d out src/Main.java` → `java -cp out Main` → відкрий <http://localhost:8765> |

Сторінка в браузері **оновлюється сама**: після перезапуску сервера або після збереження файлу в `web/`.
Кнопка ▶ в IntelliJ працює завжди: якщо гру вже запущено ярликом, новий запуск **сам замінює** старий сервер.

## Що де лежить

```
src/Main.java      Java-сервер: налаштування гри (зверху!), правила, «труби» до браузера (Javadoc на кожному блоці)
web/index.html     каркас сторінки (тут сховано прапорець 🚩)
web/style.css      вигляд (кольори — на початку файлу)
web/app.js         поведінка в браузері (кнопка, анімації, «розмова» з сервером, форма прапорця)
web/slides.html    презентація: профорієнтація + «як працює програма» (відкривається через slides.bat)
INSTALL.bat        підготувати ПК: Git + JDK + IntelliJ + гра + ярлики (з флешки)
start.bat          зібрати й (пере)запустити     stop.bat    зупинити     slides.bat   відкрити презентацію
reset.bat          повернути код до останнього коміту (+ запуск); зміни ховаються в git stash
check.bat          перевірити, чи готовий цей ПК
setup-station.bat  одноразове налаштування ПК-станції (STATION + ярлики + перевірка)
tools/             допоміжні скрипти й тексти повідомлень (install.ps1, export-ide-config…)
```

## Що можна змінювати

У `src/Main.java`, блок **«1. НАЛАШТУВАННЯ ГРИ»**: ім'я героя, сила удару, шанс крита, список монстрів.
У `web/style.css`, початок файлу: п'ять кольорів.

## Скрипти — коротко

* `start.bat show` — запустити сервер у цьому ж вікні (видно журнал); `start.bat noopen` — не відкривати браузер.
* `reset.bat` — повертає `src` і `web` до **останнього коміту**. Зміни **не губляться**: вони йдуть у `git stash` (`git stash list`, `git stash pop`).
  Без git використовується копія `_original` (її не можна скасувати). На ПК без файлу `STATION` спершу питає підтвердження.
* `slides.bat` — відкриває презентацію в Chrome й, якщо треба, запускає сервер.
* Інший порт: змінна середовища `PORT` (за замовчуванням 8765).

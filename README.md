# ⚔️ Побий монстра! — міні-гра для майстер-класу ОІПЗ

Невелика гра, у якій **браузер** — це «обличчя», а **Java-сервер** — «мозок».
Змінюєш правила гри в одному файлі → перезапускаєш → бачиш результат.

Потрібно: **JDK 17+** (найпростіше — портативний JDK у папці `jdk\`). Інтернет не потрібен.

## Запуск

| Спосіб | Як |
|---|---|
| **Двічі клікнути** `start.bat` | збирає й запускає; вікно саме закривається; відкрий у браузері <http://localhost:8765> |
| **IntelliJ IDEA** | відкрий папку → зелений ▶ біля `main` у `src/Main.java` (або кнопка «Запустити гру») |
| Вручну | `javac -encoding UTF-8 -d out src/Main.java` → `java -cp out Main` |

Сторінка в браузері **оновлюється сама**: після перезапуску сервера або після збереження файлу в `web/`.

## Що де лежить

```
src/Main.java      Java-сервер: налаштування гри (зверху!), правила, «труби» до браузера
web/index.html     каркас сторінки
web/style.css      вигляд (кольори — на самому початку файлу)
web/app.js         поведінка в браузері (кнопка, анімації, «розмова» з сервером)
start.bat          зібрати й (пере)запустити         stop.bat       зупинити
reset.bat          повернути код до оригіналу + запуск (для станцій)
check.bat          перевірити, чи готовий цей ПК
setup-station.bat  одноразове налаштування ПК-станції (STATION + ярлики + перевірка)
tools/             допоміжні скрипти й тексти повідомлень
```

## Що можна змінювати

У `src/Main.java`, блок **«1. НАЛАШТУВАННЯ ГРИ»**: ім'я героя, сила удару, шанс крита, список монстрів.
У `web/style.css`, початок файлу: п'ять кольорів.

## Скрипти — коротко

* `start.bat show` — запустити сервер у цьому ж вікні (видно журнал); `start.bat open` — ще й відкрити браузер.
* `reset.bat` — **стирає зміни в `src` і `web`** (через git, а без git — з копії `_original`).
  На ПК без файлу `STATION` спочатку питає підтвердження.
* Інший порт: змінна середовища `PORT` (за замовчуванням 8765).
